【手話通訳つき】担当学芸員によるギャラリートーク

戦後、日本とアメリカを拠点に、版画やコラージュにおける技法や素材を模索し続け、新しい表現を追究した内間安瑆・俊子（うちま あんせい・としこ）夫妻。
その活動の軌跡をたどる本展では、夫妻で交流のあったイサム・ノグチをはじめ、俊子が所属していたデモクラート美術家協会とのつながりなど、当時の美術界の交流にも注目します。二人の作品をあわせて見ることで、それぞれの作品世界の共通点や違いにも触れていただける機会です。担当学芸員が夫妻それぞれの作品の魅力や見どころなど、展覧会をより楽しむためのポイントを、当時の様子が感じられるエピソードも交えながらお伝えします。

事前申込は不要です。その他、必要なサポートがありましたらお気軽にご相談ください。
