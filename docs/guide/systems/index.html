聞こえにくさについて、仕事・学びの場で相談する

困っている場面と必要な方法を整理し、職場や学校の相談先につなぐガイドです。

Deaf Navi編集 · 内容・情報源の確認：2026-10-17

相談前に、場面・困りごと・希望を分ける

  • 場面：会議、オンライン授業、電話、館内放送など、どこで困っているか。
  • 困りごと：発言者が分からない、音声だけの説明を受け取れない、呼び出しに気づけない、など。
  • 希望：発言を文字でも示す、事前に資料を共有する、手話通訳や要約筆記を相談する、など。

職場で相談したいとき

まず職場の相談窓口や担当者へ、必要な方法を具体的に伝えます。障害者差別や合理的配慮について困っている場合は、ハローワークの相談窓口も確認できます。利用できる連絡方法や相談の進め方は、窓口へ確認してください。

学校や学びの場で相談したいとき

授業や試験で必要な情報の受け取り方を、学校の担当者や相談窓口と確認しましょう。支援の内容や手続きは学校・試験ごとに異なります。通級による指導などの制度は文部科学省の案内から確認でき、申請期限のある試験は早めの確認が必要です。

短く伝える文の例

会議で複数の人が同時に話すと、内容を追いにくくなります。一人ずつ話すことと、決定事項を文字で共有することを相談したいです。

選ぶ方法は一人ひとり異なります。提案した方法が合わなければ、困っている点を伝えて調整を相談しましょう。

公式情報・相談先

  • 厚生労働省：職場での障害者差別・合理的配慮の相談（新しいタブ）

    ハローワークで相談できる内容と窓口への入口を確認できます。

  • 文部科学省：特別支援教育・通級による指導（新しいタブ）

    特別支援教育の教育課程と、通級による指導などの説明があります。

  • 厚生労働省：情報・意思疎通支援（新しいタブ）

    手話通訳・要約筆記などの支援と、全国の聴覚障害者情報提供施設への入口です。
