予約前に確認しておくこと

  • 会話と連絡：手話・筆談など希望する会話方法、到着が遅れるときの連絡手段、夜間にスタッフへ連絡する方法を確認しましょう。手話で対応できる宿でも、時間帯によって対応できる人が不在の場合があります。希望する方法でやりとりできるか、事前に相談しておくと安心です。
  • 部屋と共用設備：個室か相部屋か、階段の有無、浴室・トイレの共用範囲。ペットや子どもと泊まる場合は受入条件も確認します。
  • 支払総額と取消条件：1人料金か1室料金か、宿泊税・冷暖房費・予約サイトの手数料、人数や日程を変える場合の扱い。最安値の表示だけで比べず、同じ条件で確認します。
  • 非常時の知らせ方：光・振動などの設備の有無と使い方、避難口、夜間の対応。記載のない設備は「ない」と断定せず、宿へ確認してください。
