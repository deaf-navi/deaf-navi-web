手話通訳・字幕・要約筆記・筆談を確認するとき

イベントや生活の用事に参加する前に、自分が情報を受け取りやすい方法を確認するガイドです。

Deaf Navi編集 · 内容・情報源の確認：2026-10-17

手話の催しでも、対応する方法は同じとは限りません

手話で表現される公演、手話通訳のある講演、字幕のある映像などでは、情報の受け取り方が違います。「手話に関係するイベント」だけで判断せず、必要な方法がどの場面で利用できるかを告知や主催者に確認しましょう。

告知や主催者に確認すること

  • 手話通訳：講演だけか、受付・質疑応答・交流の時間にも対応するか。
  • 字幕・要約筆記：表示方法、表示する範囲、席からの見え方。
  • 筆談：受付でのやり取りや、個別の質問に利用できるか。
  • 申込：事前の申し出、申込期限、費用、用意するものがあるか。

生活の用事で通訳・要約筆記を依頼したいとき

市区町村の障害福祉窓口や地域の聴覚障害者情報提供施設へ相談できます。対象となる場面、登録の要否、申込期限、費用は地域や制度によって異なります。希望する方法、日時、場所、用事をまとめて相談すると伝えやすくなります。

問い合わせに使える文の例

このイベントへの参加を考えています。私は文字で情報を受け取りたいです。講演と質疑応答には、字幕または要約筆記がありますか。事前の申込が必要なら、方法と期限を教えてください。

Deaf Naviの「情報の受け取り方」は、告知で確認できたものを表示しています。「未確認」は「対応なし」を意味しません。
